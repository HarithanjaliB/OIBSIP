# Number Guessing Game

## Description
A Java-based game where the user guesses a randomly generated number between 1 and 100.

## Features
- Random number generation
- 10 attempts limit
- Multiple rounds
- Score calculation
- High/Low hints

## Technology Used
Java

## How to Run
javac NumberGuessingGame.java
java NumberGuessingGame
