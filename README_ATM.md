# ATM Interface

## Description
A Java-based ATM application that allows users to perform banking operations such as checking balance, depositing money, withdrawing money, and viewing transaction history.

## Features
- User Login
- Deposit Money
- Withdraw Money
- Check Balance
- Transaction History
- Exit Option

## Technology Used
Java

## How to Run
javac ATMInterface.java
java ATMInterface
